# Module 01 — Introduction to SQL

> Build a strong foundation before writing complex queries.

This module introduces SQL, databases, relational database concepts, SQL command categories, query components, and professional SQL coding style.

## Learning objectives

By the end of this module, you should be able to:

- Explain what SQL is and why it is used.
- Distinguish a database, DBMS, and RDBMS.
- Identify common database types and understand SQL vs. NoSQL at a high level.
- Classify common SQL commands as DDL, DML, DQL, DCL, or TCL.
- Recognize the main components of a SQL statement.
- Write readable, safer SQL using consistent formatting.

## SQL dialect

Examples in this repository use **MySQL 8.0+**. Most introductory concepts are common across relational database systems, but syntax and behavior can differ between MySQL, PostgreSQL, SQL Server, and Oracle.
