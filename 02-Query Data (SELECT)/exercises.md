# Module 02: Hands-on Exercises

Use the `employees` table created by [`practice.sql`](practice.sql). Try each question yourself before checking your query.

## Easy

1. Display all columns from `employees`.
2. Display only employee names and cities.
3. Find employees working in the IT department.
4. Find employees earning more than 60000.
5. Find employees located in Delhi.
6. Display employees whose names begin with `A`.
7. Display employees whose `manager_id` is NULL.

## Medium

8. Find employees earning between 50000 and 70000.
9. Find employees in IT or Finance using `IN`.
10. Sort employees by salary from highest to lowest.
11. Sort by city ascending, then joining date newest first.
12. Display each distinct department.
13. Display the three highest-paid employees.
14. Count employees in each department.
15. Calculate average salary for each department.
16. Find the highest salary in each city.

## Challenge

17. Find departments with at least two employees.
18. Find departments whose average salary is greater than 55000.
19. For employees outside Mumbai, calculate employee count and average salary by department; show only departments with at least two employees.
20. Return the two departments with the highest average salary.
