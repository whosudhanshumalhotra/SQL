# SQL From Zero to Advanced

A structured, hands-on SQL learning repository covering fundamentals through advanced querying, optimization, and practical projects.

## Learning path

1. **01 — Introduction**: SQL fundamentals, databases, command categories, query components, coding style.
2. **02 — Query Data (SELECT)**
3. **03 — Data Definition (DDL)**
4. **04 — Data Manipulation (DML)**
5. **05 — Filtering Data**
6. **06 — Combining Data**
7. **07 — Row-Level Functions**
8. **08 — Aggregation & Analytical Functions**
9. **09 — Advanced SQL Techniques**
10. **10 — Performance Optimization**
11. **11 — AI & SQL**
12. **12 — SQL Projects**

## How to use this repository

- Follow modules and lessons in order.
- Type and run the SQL examples yourself.
- Complete exercises before checking notes.
- Practise explaining interview answers aloud.
- Add each new module as you progress.

## SQL dialect

Examples use MySQL 8.0+ unless a lesson explicitly says otherwise. Dialect-specific behavior is called out where relevant.
